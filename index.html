난이도별 일반화 능력 재검토: 쉽지 않네
Yeganeh Kordi et al.
요약 (Abstract)
**LLM의 과제 난이도 일반화 연구** 저희는 대규모 언어 모델(LLM)이 다양한 과제 난이도에서 얼마나 잘 일반화되는지, 효과적인 데이터 큐레이션 및 평가를 위한 핵심 질문을 탐구합니다. 기존 연구는 더 쉬운 데이터 또는 더 어려운 데이터를 학습하는 것이 더 나은 결과를 가져오는지, 그리고 이러한 이점이 더 쉬운 테스트 데이터 또는 더 어려운 테스트 데이터에서 나타나는지에 대한 의견이 분분합니다. 저희는 모델, 데이터 세트 및 예시 난이도의 세분화된 그룹에 걸쳐 LLM의 일반화를 체계적으로 평가하여 이 질문에 답합니다. 교육 테스트에서 널리 사용되는 난이도 측정 지표인 Item Response Theory (IRT)와 수천 개의 서로 다른 LLM의 출력을 사용하여 6개의 데이터 세트에서 예시의 순위를 매깁니다. 이전 연구와 달리, 저희의 난이도 평가는 인간의 난이도 판단을 배제하고 다양한 LLM의 능력만으로 결정됩니다. 더욱 객관적이고 대규모이며 세분화된 분석을 통해, 난이도 간 일반화가 종종 제한적임을 보여줍니다. 즉, 쉬운 데이터 또는 어려운 데이터 중 어느 쪽으로 학습하더라도 전체 난이도 범위에서 일관된 개선을 달성할 수 없습니다. 이러한 결과는 LLM의 학습 및 평가 데이터 모두에서 다양한 난이도를 갖는 것의 중요성을 보여주며, 난이도에 대한 지름길을 택하는 것은 위험하다는 것을 나타냅니다.

TraceGen: 3D Trace 공간에서의 월드 모델링을 통한 교차-구현 비디오 학습
Seungjae Lee et al.
요약 (Abstract)
새로운 플랫폼과 환경에서 소수의 데모만으로 새로운 로봇 작업을 학습하는 것은 여전히 어려운 과제입니다. 인간과 다른 로봇의 다양한 구현 형태에 대한 비디오는 풍부하지만, 구현, 카메라, 그리고 환경의 차이로 인해 직접적인 사용이 어렵습니다. 저희는 교차 구현, 교차 환경, 그리고 교차 작업 비디오로부터 학습할 수 있게 해주는 통합된 기호적 표현, 즉 장면 수준의 궤적에 대한 압축된 3D "트레이스 공간"을 도입하여 적은 데이터 문제를 해결합니다. TraceGen을 통해, 저희는 픽셀 공간 대신 트레이스 공간에서 미래의 움직임을 예측하는 세계 모델을 제시하며, 조작에 필요한 기하학적 구조를 유지하면서 외관을 추상화합니다. TraceGen을 대규모로 학습시키기 위해, 저희는 이질적인 인간 및 로봇 비디오를 일관된 3D 트레이스로 변환하는 데이터 파이프라인인 TraceForge를 개발하여, 123,000개의 비디오와 180만 개의 관찰-트레이스-언어 삼중항으로 구성된 코퍼스를 생성했습니다. 이 코퍼스에서 사전 훈련을 수행하면 효율적으로 적응하는 이전 가능한 3D 동작 사전이 생성됩니다. 단 5개의 대상 로봇 비디오만으로, TraceGen은 4가지 작업에서 80%의 성공률을 달성하는 동시에 최첨단 비디오 기반 세계 모델보다 50~600배 빠른 추론 속도를 제공합니다. 핸드헬드 폰으로 캡처된 5개의 보정되지 않은 인간 데모 비디오만 사용 가능한 더 어려운 경우에도, 실제 로봇에서 67.5%의 성공률을 달성하여, TraceGen이 객체 감지기나 무거운 픽셀 공간 생성을 사용하지 않고도 구현 형태 간에 적응할 수 있는 능력을 강조합니다.

ToolOrchestra: 효율적인 모델 및 도구 오케스트레이션을 통한 지능 향상
Hongjin Su et al.
요약 (Abstract)
제목: 소형 오케스트레이터를 활용한 효율적인 도구 사용 에이전트 거대 언어 모델(LLM)은 강력한 제너럴리스트이지만, Humanity's Last Exam (HLE)과 같은 심층적이고 복잡한 문제를 해결하는 것은 여전히 개념적으로 어렵고 계산 비용이 많이 듭니다. 본 연구에서는 다른 모델과 다양한 도구를 관리하는 소형 오케스트레이터가 지능의 상한을 높이는 동시에 어려운 에이전트 작업 해결의 효율성을 향상시킬 수 있음을 보입니다. 저희는 지능형 도구를 조정하는 소형 오케스트레이터 훈련 방법인 ToolOrchestra를 소개합니다. ToolOrchestra는 결과, 효율성, 사용자 선호도를 고려한 보상과 함께 강화 학습을 명시적으로 사용합니다. ToolOrchestra를 사용하여, 저희는 주어진 쿼리에 어떤 도구를 사용할지에 대한 사용자 선호도에 맞춰 이전의 도구 사용 에이전트보다 낮은 비용으로 더 높은 정확도를 달성하는 80억 파라미터 모델인 Orchestrator를 제작했습니다. HLE에서 Orchestrator는 GPT-5 (35.1%)를 능가하는 37.1%의 점수를 달성했으며, 효율성은 2.5배 더 높았습니다. tau2-Bench 및 FRAMES에서 Orchestrator는 GPT-5를 큰 차이로 앞지르면서, 비용은 약 30%만 사용했습니다. 광범위한 분석 결과, Orchestrator는 여러 지표에서 성능과 비용 간의 최적의 균형을 달성했으며, 보이지 않는 도구에도 강력하게 일반화됩니다. 이러한 결과는 경량 오케스트레이션 모델로 다양한 도구를 구성하는 것이 기존 방법보다 더 효율적이고 효과적임을 보여주며, 실용적이고 확장 가능한 도구-보강 추론 시스템의 길을 열어줍니다.

G$^2$VLM: 통합 3D 재구성과 공간 추론을 갖춘 기하 기반 시각 언어 모델
Wenbo Hu et al.
요약 (Abstract)
시각-언어 모델(VLM)은 여전히 공간 지능 측면에서 견고함이 부족하며, 공간 이해 및 추론 작업에서 낮은 성능을 보입니다. 이러한 격차는 2D 이미지로부터 3D 공간을 재구성할 수 있는 시각적 기하학 학습 과정의 부재에 기인한다고 봅니다. 저희는 공간 지능의 두 가지 근본적인 측면인 공간 3D 재구성 및 공간 이해를 연결하는 기하학 기반 시각-언어 모델인 G$^2$VLM을 제안합니다. G$^2$VLM은 학습된 3D 시각 기하학적 특징을 기본적으로 활용하여 3D 속성을 직접 예측하고, in-context learning과 interleaved reasoning을 통해 공간 추론 작업을 향상시킵니다. 저희의 통합 설계는 공간 이해에 매우 확장 가능하며, 풍부한 멀티뷰 이미지 및 비디오 데이터로 학습하는 동시에, 수집하기 어려운 주석에서 일반적으로 파생되는 3D 시각적 사전 지식의 이점을 활용합니다. 실험 결과는 G$^2$VLM이 두 작업 모두에서 뛰어나, 최첨단 feed-forward 3D 재구성 모델과 유사한 결과를 달성하고, 공간 이해 및 추론 작업 전반에서 더 우수하거나 경쟁력 있는 결과를 얻는 것을 보여줍니다. 의미적으로 강력한 VLM과 저수준 3D 시각 작업을 통합함으로써, G$^2$VLM이 커뮤니티를 위한 강력한 기반이 되고 3D 장면 편집과 같은 미래 응용 분야를 더 많이 열어갈 수 있기를 바랍니다.

Matrix: 피어-투-피어 멀티-에이전트 합성 데이터 생성 프레임워크
Dong Wang et al.
요약 (Abstract)
**Matrix: 분산형 합성 데이터 생성 프레임워크** 합성 데이터는 대규모 언어 모델(LLM) 학습에 있어 점점 더 중요해지고 있으며, 특히 실제 데이터가 부족하거나, 비용이 많이 들거나, 개인 정보 보호에 민감한 경우에 더욱 그렇습니다. 이러한 많은 생성 작업은 전문 에이전트들이 협력하여 더 높은 품질, 더 다양한, 그리고 구조적으로 더 풍부한 데이터를 생성하는, 조정된 다중 에이전트 워크플로우를 필요로 합니다. 그러나 기존 다중 에이전트 합성을 위한 프레임워크는 종종 중앙 집중식 오케스트레이터에 의존하여 확장성 병목 현상을 유발하거나 특정 도메인에 하드코딩되어 유연성을 제한합니다. 저희는 제어 및 데이터 흐름을 분산 큐를 통해 전달되는 직렬화된 메시지로 표현하는 분산형 프레임워크인 \textbf{Matrix}를 제시합니다. 이 피어 투 피어(peer-to-peer) 디자인은 중앙 오케스트레이터를 제거합니다. 각 작업은 경량 에이전트를 통해 독립적으로 진행되는 반면, LLM 추론 또는 컨테이너화된 환경과 같은 컴퓨팅 집약적인 작업은 분산 서비스를 통해 처리됩니다. Ray를 기반으로 구축된 Matrix는 수만 개의 동시 에이전트 워크플로우로 확장 가능하며, 광범위한 데이터 생성 워크플로우에 쉽게 적응할 수 있도록 모듈식으로 구성 가능한 설계를 제공합니다. 저희는 다중 에이전트 협업 대화, 웹 기반 추론 데이터 추출, 그리고 고객 서비스 환경에서의 도구 사용 궤적 생성과 같은 다양한 합성 시나리오에서 Matrix를 평가했습니다. 모든 경우에 Matrix는 동일한 하드웨어 리소스 하에서 출력 품질을 저하시키지 않으면서 $2$--$15\times$ 더 높은 데이터 생성 처리량을 달성했습니다.
