Abstract (Translated)
합성 데이터는 대규모 언어 모델을 훈련하는 데 점점 더 중요해지고 있으며, 특히 실제 데이터가 부족하거나, 비용이 많이 들거나, 개인 정보 보호에 민감한 경우에 그렇습니다. 이러한 생성 작업 중 다수는 조정된 멀티 에이전트 워크플로우를 필요로 하며, 여기서 전문 에이전트가 협력하여 더 높은 품질, 더 다양한 구조적으로 풍부한 데이터를 생성합니다. 그러나 멀티 에이전트 합성을 위한 기존 프레임워크는 종종 중앙 집중식 오케스트레이터에 의존하여 확장성 병목 현상을 만들거나 특정 도메인에 대해 하드 코딩되어 유연성을 제한합니다. 우리는 제어 및 데이터 흐름을 분산된 큐를 통해 전달되는 직렬화된 메시지로 표현하는 분산 프레임워크인 \textbf{Matrix}를 제시합니다. 이 피어 투 피어 디자인은 중앙 오케스트레이터를 제거합니다. 각 작업은 경량 에이전트를 통해 독립적으로 진행되는 반면, LLM 추론 또는 컨테이너화된 환경과 같은 계산 집약적인 작업은 분산 서비스에서 처리됩니다. Ray를 기반으로 구축된 Matrix는 수만 개의 동시 에이전트 워크플로우로 확장되며, 광범위한 데이터 생성 워크플로우에 쉽게 적응할 수 있는 모듈식 구성 가능한 디자인을 제공합니다. 우리는 Matrix를 멀티 에이전트 협업 대화, 웹 기반 추론 데이터 추출, 고객 서비스 환경에서 도구 사용 궤적 생성과 같은 다양한 합성 시나리오에서 평가합니다. 모든 경우에 Matrix는 동일한 하드웨어 리소스에서 출력 품질을 저하시키지 않으면서 $2$--$15\times$ 더 높은 데이터 생성 처리량을 달성합니다.
